# ADR 0007: S ランク 11 設問による材質・環境タイプ体系、物理導出ステータス、不確実度レア度を採用する

## Status

Accepted

## Context

`LiquidAI/d1-2B` は 1 forward で最大 16 問の型付き質問に回答できるが、抽象的なファンタジー属性（「炎・雷」等の直接質問）や抽象ステータス（「HP・防御力」の直接評価）をそのまま尋ねると、背景への引きずりや分布の平坦化が起きやすい。Phase 0 で 12 枚の多様な実画像に対して全 23 候補（カテゴリ 9 問・スカラー 14 問）を実測検証した結果、以下の事実が得られた。

- 物理的・視覚的に根拠のある 5 カテゴリ（`substance`, `biome`, `archetype`, `size_class`, `is_living`）と 6 スカラー（`size_7`, `mass_5`, `power`, `agility`, `mystique`, `warmth`）の計 11 問が、高い分離精度・確信度・値域レンジ（S ランク）を示した。
- とくに 7 段階対数実寸（`size_7`、レンジ 0.927）と 5 段階対数質量（`mass_5`、レンジ 0.814）は、マクロ撮影の虫から火山・稲妻まで実寸順が完全に一致し、サイズと重さの差分によって「巨大×軽量（稲妻・精霊）」と「巨大×超重量（城・岩）」を明確に分離できた。
- 一方、直接属性（`element`）は猫・アヒルが背景の芝に引かれて `flora` 寄りになり、直接の `vitality` / `toughness` / `complexity` も物理軸より分離が弱かった。
- さらに、各設問の確率分布に対する正規化シャノンエントロピー（予測不確実度）は、典型的な被写体ほど低く、複数概念が混在する希少・境界的な画像ほど高くなる性質を示した。

## Decision

クリーチャー生成の判定モデルを以下の **S ランク 11 設問 ＋ 決定論的導出式** に確定する。

1. **設問セット（11 問 / 1 forward）**:
   - **カテゴリ系（5 問）**: `substance`（7 材質）, `biome`（6 生息域）, `archetype`（6 クラス）, `size_class`（7 体格区分、`intangible` 含む）, `is_living`（生物判定 `noul`）
   - **スカラー系（6 問）**: `size_7`（対数 7 段階実寸）, `mass_5`（対数 5 段階重さ）, `power`（攻撃性）, `agility`（敏捷性）, `mystique`（神秘性）, `warmth`（親しみ）
2. **タイプ体系（案 1: 材質×環境＋クラス）**:
   - **主タイプ（バトル相性軸）**: `substance`（`flesh` / `botanical` / `metal` / `stone` / `liquid` / `fabric` / `energy`）。確率 2 位が 20% 以上なら複合タイプを付与する。
   - **副タイプ（環境軸）**: `biome`（`wild` / `aquatic` / `urban` / `sky` / `abyss` / `cosmos`）。
   - **クラス（役割軸）**: `archetype`（`beast` / `guardian` / `spirit` / `construct` / `flora` / `trickster`）。
3. **ステータス決定（HP / DEF は物理軸から純粋関数で算出）**:
   - **ATK / SPD / SP**: `power` / `agility` / `mystique` の期待値から直接算出する。
   - **HP**: `size_7`（45%）+ `mass_5`（35%）+ `is_living`（10%）+ `warmth`（10%）から算出する。
   - **DEF**: `mass_5`（45%）+ 密度 `(mass_5 - size_7 + 1) / 2`（25%）+ `substance` 確率分布で重み付けした材質硬度（30%）から算出する。
4. **レア度（不確実度ベース）**:
   - 11 問の正規化シャノンエントロピー $H_{\text{norm}} \in [0, 1]$ から合成不確実度 $U = 0.6 H_{\text{type}} + 0.4 H_{\text{scalar}}$ を算出し、実測分布に基づき `COMMON` / `UNCOMMON` / `RARE` / `EPIC` / `MYTHIC` の 5 段階へ写像する（追加設問 0）。

## Consequences

### Pros

- 設問数が 16 問から 11 問（suffix 約 1,287 トークン）へ縮小され、1 forward の推論負荷がさらに軽くなる。
- 物理的根拠の強い S ランク設問のみを使うため、日常のあらゆる写真に対してタイプ・体格・ステータスの納得感が高い。
- HP / DEF / レア度の導出式が純粋関数として分離されているため、モデル再推論なしで v2 バトル向けのバランス調整・再計算が可能。
- 追加の「レア度設問」を設けずに、モデルの自然な迷い（不確実度）をゲーム的な希少性へ昇華できる。

### Cons

- 伝統的な RPG の「炎・氷・雷」といった属性名ではなく、材質×環境ベースの博物誌的なタイプ体系となる。
- レア度閾値は設問セット変更時にエントロピー分布が変化するため、設問改定のたびに実測再キャリブレーションが必要になる。
