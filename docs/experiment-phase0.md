## 3. 不確実度からのレア度算出

各設問の確率分布 $p = (p_1, \dots, p_K)$ に対し正規化シャノンエントロピーを算出:

$$H_{\text{norm}}(p) = \frac{-\sum_i p_i \ln p_i}{\ln K} \in [0, 1]$$

カテゴリ系平均 $H_{\text{type}}$（重み 0.6）とスカラー系平均 $H_{\text{scalar}}$（重み 0.4）の合成値 $U = 0.6 H_{\text{type}} + 0.4 H_{\text{scalar}}$ を測定したところ、9 画像で `0.403〜0.678`（中央値 `0.506`）に分布した。

- 典型的な被写体（猫 `0.403`、森のシダ `0.419`）はモデルが迷わず確信するため **COMMON**。
- 複数属性・複数概念が混在する珍しい構図（薄暮の稲妻 `0.593`、ISS から撮影したエトナ火山噴火 `0.678`）ほどモデルが複数候補で揺れるため **EPIC / MYTHIC** へ自然に昇格する。
- 実測値に基づき [`src/inference/readout.ts`](../src/inference/readout.ts) の閾値を `common (<0.44)` / `uncommon (0.44–0.51)` / `rare (0.51–0.58)` / `epic (0.58–0.65)` / `mythic (>=0.65)` にキャリブレーション済み。
